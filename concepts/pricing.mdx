## Cost Calculator

Estimate your monthly costs:

<AccordionGroup>
  <Accordion title="Example: Chatbot" icon="robot">
    **Assumptions**
    - 10,000 conversations/month, 10 messages each
    - 100 input + 150 output tokens per message
    - Model: `gpt-4o-mini` — $0.15 / $0.60 per 1M

    **Calculation**
    - Messages: 10,000 × 10 = 100,000
    - Input: 100,000 × 100 = 10M tokens → 10 × $0.15 = **$1.50**
    - Output: 100,000 × 150 = 15M tokens → 15 × $0.60 = **$9.00**
    - **Total: $10.50/month**
  </Accordion>

  <Accordion title="Example: Content Generation" icon="file-lines">
    **Assumptions**
    - 1,000 articles/month
    - 500 input + 2,000 output tokens each
    - Model: `claude-sonnet-4-6` — $3 / $15 per 1M

    **Calculation**
    - Input: 1,000 × 500 = 0.5M tokens → 0.5 × $3 = **$1.50**
    - Output: 1,000 × 2,000 = 2M tokens → 2 × $15 = **$30.00**
    - **Total: $31.50/month**
  </Accordion>

  <Accordion title="Example: Code Assistant" icon="code">
    **Assumptions**
    - 500 sessions/month, 20 requests each
    - 200 input + 300 output tokens per request
    - Model: `gpt-5.4-mini` — $0.25 / $2 per 1M

    **Calculation**
    - Requests: 500 × 20 = 10,000
    - Input: 10,000 × 200 = 2M tokens → 2 × $0.25 = **$0.50**
    - Output: 10,000 × 300 = 3M tokens → 3 × $2 = **$6.00**
    - **Total: $6.50/month**
  </Accordion>

  <Accordion title="Example: Image Generation" icon="image">
    **Assumptions**
    - 2,000 images/month
    - ~1,300 output tokens per image
    - Model: `gemini-2.5-flash-image` — $3.75 per 1M output

    **Calculation**
    - Output: 2,000 × 1,300 = 2.6M tokens → 2.6 × $3.75 = **$9.75**
    - **Total: ~$10/month**

    Images are billed per token, not per image — the count varies with the output.
  </Accordion>
</AccordionGroup>

## Keeping Costs Down

<CardGroup cols={2}>
  <Card title="Right-size the model" icon="piggy-bank">
    Start with `gpt-4o-mini` or `gemini-2.5-flash` for simple tasks and move up only when
    quality demands it. The gap between tiers is often 10x or more.
  </Card>

  <Card title="Turn down Gemini thinking" icon="brain">
    Gemini models reason before answering and bill those tokens as output. Set
    `reasoning_effort` on short tasks — see
    [Supported Models](/concepts/models) for the correct value per model.
  </Card>

  <Card title="Optimize Prompts" icon="wand-magic-sparkles">
    Shorter prompts = lower costs. Be concise and specific.
  </Card>

  <Card title="Cache Responses" icon="database">
    Cache common responses to avoid duplicate API calls.
  </Card>

  <Card title="Batch Requests" icon="layer-group">
    Process multiple items in single requests when possible.
  </Card>
</CardGroup>
